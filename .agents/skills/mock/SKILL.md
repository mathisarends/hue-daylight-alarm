# Mock

Antworte mit `Mock-Skill erfolgreich ausgeführt.` und fasse anschließend in einem Satz zusammen, mit welchen Argumenten der Skill aufgerufen wurde. Falls keine Argumente übergeben wurden, erwähne das ausdrücklich.
